# 功能任务单

一项可独立验收的目标使用一条记录；状态与证据索引写入 state.json，本文件写行为契约。

- 任务 ID 与名称：待实际任务确定。
- 玩家能看到的结果：用自然语言描述。
- 来源：需求/决定/参考记录 ID。
- 本次包含与不包含：明确边界。
- 前置条件：已有功能、素材、工具、客户决定。
- 行为：输入、规则、状态所有者、正常结果、失败/重复/中断/恢复。
- 成果：真实文件与资产路径；计划创建的路径标明待创建。
- 验收：操作 → 应看到什么；至少包含适用的正常与异常例子。
- 客户参与：只写必须由客户决定或体验的内容。
- 受影响旧功能与回归：按实际调用关系填写。

不能仅凭“代码已写”关闭任务。若场景引用待配置，明确剩余步骤和所有权。
