# 新手证件审核游戏开发工作流 V0.2

这套工作流帮助没有游戏开发经验的客户，在 AI 引导下完成一款《Papers, Please》式游戏：从确定具体体验，到完整内容、测试、打包、发行准备和发布后维护。原型只是过程中的一次验证。

## 从这里开始

收到 ZIP 后请先完整解压，打开根目录的 `先看这里.txt`。发送方式与客户短消息见 [交付与发送说明](docs/客户交付与发送说明.md)。

1. 将整个文件夹保存在本机，保留隐藏的 `.agents` 文件夹。**先把已有世界观、剧情、玩法笔记和参考图发给 Codex，或放进 `00_客户资料/`。不需要先整理成专业格式。**
2. 用 Codex 打开这个文件夹，让它先清点、阅读已有资料，并告诉你已经理解了什么、还缺什么；已经写清楚的内容不重新问一遍。
3. 双击根目录的 `启动进度网页.cmd`。首次需要 Python 3.10 或更高版本；网页本身不需要网络或 API Key。
4. 在网页里看“现在做什么”，复制“继续这一步”的文字到 Codex。
5. 也可以直接说：**“请先阅读我发给你的资料和 `00_客户资料`，概括已确定内容、矛盾和缺口，再按本项目工作流带我继续。我没有游戏开发经验，类型已经确定是 Papers, Please 这种，只问目前资料无法回答且现在必须决定的问题。”**

首次设置详见 [从这里开始](01_客户指南/01_从这里开始.md)。关闭启动窗口会停止网页服务，不会删除进度。

## 使用边界

- 已确定的是游戏类型；具体背景、剧情和其他决定先从客户资料提取。尚未收到或读到的内容保持“待读取/待核验”，不等同于客户尚未设计，也不由 AI 替客户作决定。
- 网页会每 3 秒读取本地记录。它不会直接运行 AI；复制提示词后，在 Codex 对话里执行。反馈保存后，AI 在下次读取项目时处理。
- 所有任务起始都未验收。示例不算实际项目成果，网页进度不代表工期估计。
- 第一版交付的是工作流工具和材料，未包含已开发完成的 Unity 游戏，也不能保证未经实际使用检验的客户一定独立完成。
- 不自动登录发行平台、不代付、不自动发布。发行平台及商业条款在实际发布阶段核验。

本地 skills 的发现路径依据 [OpenAI 官方技能文档](https://learn.chatgpt.com/docs/build-skills)，实际文件统一放在 `.agents/skills/`，`03_Skills` 提供使用入口，避免两份技能不同步。
