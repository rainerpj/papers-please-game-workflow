# 工作流交付包交接 V0.3

## 目标与当前成果

帮助零经验客户完成约定范围内的 Papers, Please 式完整游戏及交付维护。此目录是工作流包，不是 Unity 工程。V0.2 的完整生命周期、资料接收和新手走查修复保持；V0.3 按用户授权加入自我迭代机制，完成本地自查测试后提交推送，并更新客户 ZIP。

需求权威为项目记录下设计/范围文件；游戏进度唯一权威为 `项目记录/state.json`；阶段为 workflow.json；工作流改进唯一权威为 `项目记录/工作流改进.json`。启动先读已有客户资料，不重复询问已确定的类型或设定。

## V0.3 改动

- 新增 beginner-workflow-improve；guide/AGENTS 默认挂接纠正、任务收尾及周期复盘，review 处理归因与效果证据。共 7 个 skills。
- improvement.py 与独立 JSON：来源覆盖与游标、去重、归因、prepare/seal、四项检查、trial/observe、rollback/cancel、恢复日志、任务和周期复盘。沿用本地写锁，revision 独立。
- workflow.py：协作反馈 scope 与 route_feedback；保持原文/分类理由，协作问题不阻断游戏验收；新增完成事件供周期判断。
- server.py/app.js/index.html：独立改进接口和页面、反馈分类与草稿保留、记录损坏时保留游戏页面。网页不运行 AI。
- 客户指南 09、持续改进规范、操作协议、案例模板与新提示词 2 条；共 22 条。入口 README/先看这里/交付短消息升级 V0.3。
