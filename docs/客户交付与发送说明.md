# 客户交付与发送说明

## 发什么

发送 `游戏开发工作流_V0.2_客户交付.zip` 这一个文件即可，微信按“文件”发送，邮件作为附件添加。若客户端提示大小或附件类型限制，可使用双方认可的文件传输方式，不拆散工作流目录。

ZIP 包含完整工作流、六个 skills、网页代码、指南、模板、提示词、初始项目记录与测试/验收材料；不包含 `.git`、Python 缓存、运行锁、进度备份和打包产物。客户不需要 GitHub 账户，也不需要先下载 Git。

客户收到后先在 Windows 电脑完整解压，再用 Codex 打开最外层项目文件夹。不要在压缩包预览中运行启动脚本，不要漏掉隐藏的 `.agents` 目录。入口是根目录 `先看这里.txt`。

这是完整工作流交付，不含 Codex/Unity 账户、已安装的 Python/Unity、最终游戏或代付资源服务。已有资料先提供给 Codex，环境由它按实际机器检查。

## 可直接发送的短消息

游戏开发工作流打包好了。请先把 ZIP 完整解压到电脑，用 Codex 打开解压后的整个文件夹。把已有世界观、剧情和参考资料放进「00_客户资料」，或直接发给 Codex，然后说：「请先读我的资料，按这套工作流带我开始，我没有游戏开发经验。」双击「启动进度网页.cmd」就能看进度；打不开时把提示原话发给 Codex。之后跟着当前步骤走就行，不用先读完所有文档。

## 交付检查

打包采用已提交版本的文件清单，保留隐藏 skills 和中文文件名。交付前检查 ZIP 能完整读取，解压到隔离目录后检查链接、状态结构、环境预检及状态/HTTP 测试。版本来源与实际结果记录在 ZIP 旁的打包记录中。用户没有要求实际发送消息，本次只准备文件和文案。
