# 模板与真实记录

本目录是新项目的记录模板，不能作为已完成证据。`项目记录/` 是本次客户游戏的实际记录；AI 根据客户回答逐步填写，不要求客户编辑 Markdown 或 JSON。

当前项目已初始化类型方向，其余没有客户依据的内容保持待确定。新客户项目应复制整个干净交付包并重新初始化记录，不沿用其他客户的状态、素材或私人反馈。已有项目不覆盖初始化。

记录数量随实际需要增加。复杂功能按任务 ID 拆文件，简单功能保留在一张任务单即可。模板中的空格和说明不能被提交为验收证据。

设计文档采用 `[Proposal]` 提案、`[To Decide]` 待决定、`[To Prototype]` 待原型验证、`[Confirmed]` 已确认等标记；任务进度仍只由 state.json 管理。这两种状态分别描述决定与执行，不互相替代。

新增 [本步操作卡](本步操作卡.md) 与 [交付版本清单](交付版本清单.md)：由 AI 按当前真实环境填写，不要求客户维护模板。

[工作流改进案例](工作流改进案例.md) 用于记录问题来源、原情境、相邻情境及试用效果。由 AI 填写，客户不用填表。
