# 持续竞品参考记录

主参考方向由客户指定为 Papers, Please。本记录目前没有已核验的具体机制结论。遇到疑点时填写一条聚焦记录；不要求客户先提出专业研究问题。

## 单条记录结构

- REF 编号、日期、关联任务、当前疑点与需要支持的决定。
- 作品、版本/平台、来源链接、访问日期、视频时间点/文档位置。
- 证据方式：实际试玩 / 视频观察 / 官方文字 / 待核验。
- 观察事实：来源实际支持的行为。
- 推断：可能的体验效果或设计动机，明确不是已知事实。
- 本项目适用条件、不适用部分与制作成本。
- 方案与建议：少量有差异的选择，或最小对照实验。
- 决定：采用 / 调整 / 拒绝 / 待实验；决定人、理由、需求和任务 ID。
- 后续验证：实际结果、是否保留、更新了哪条正式规则。

研究完成不代表功能已制作。没有来源时保留为待查证假设。
