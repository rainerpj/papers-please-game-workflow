# 第一次打不开怎么办

不需要先学会排查电脑。记下你停在哪一步，把当前看到的提示原话交给 Codex。

| 看到的情况 | 现在做什么 |
|---|---|
| 不知道从哪个文件开始 | 双击项目根目录的“启动进度网页.cmd”；保留打开的服务窗口 |
| 提示 Python 不可用或版本太旧 | 说“请检查这个项目的 Python 启动环境，帮我安装或选择可用版本”；AI 检查后给具体步骤 |
| 浏览器没有自动打开 | 在服务窗口找“本地进度网页”后的地址，复制到浏览器；没有地址就把错误原话交给 AI |
| 提示端口无法使用 | 让 AI 检查已有服务是不是本项目；不能确定时换端口，不随意结束其他程序 |
| 页面显示连接中断 | 检查启动窗口是否被关掉；重新启动一次；仍失败就把提示告诉 AI，不反复刷新 |
| Codex 看不到文件 | 确认选择了整个项目文件夹，告诉它资料所在位置；不用重新写全部设定 |
| 图片或 Unity 相关工具不可用 | 先继续资料整理和方向讨论；AI 会说明需要你操作的部分或可用替代路线 |

准备好时，你能打开本步说明、看见 AI 更新后的记录版本、保存一条反馈并得到答复。网页打开本身不代表游戏或 Unity 已安装好。

若暂时没有可用 AI，把错误保存下来，恢复对话后说：“我卡在这里，请先看这条错误和交接记录，从这个位置继续。”
