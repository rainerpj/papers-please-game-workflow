# 七个 skills 怎样配合

客户通常只用“带我继续”一句话，由总引导选择专业技能。技能正文统一放在项目根目录的 `.agents/skills/`，不需要复制到个人全局目录。请交付整个文件夹并保留隐藏目录。

| 名称 | 什么时候使用 |
|---|---|
| beginner-game-guide | 开始、继续、卡住、进度、交接；默认入口 |
| beginner-game-design | 把想法写成规则、内容和完整版本范围 |
| beginner-unity-2d | 程序、场景装配、测试、构建、问题修复 |
| beginner-game-art | 风格、资产提示词、生成规格、接入验收 |
| beginner-game-reference | 任意阶段的玩法、叙事、美术、交互疑点 |
| beginner-game-review | 每步自审、阶段审查、证据和验收 |

本项目中也可明确说：“请使用 beginner-game-reference，帮我判断为什么这个界面看起来很乱。”技能未出现在客户端列表时，让 AI 直接读取 `.agents/skills/对应名称/SKILL.md`，执行同一流程。不要安装其他人的同名技能来掩盖加载问题。

按 [OpenAI 官方文档](https://learn.chatgpt.com/docs/build-skills)，仓库技能使用 `.agents/skills`，可以由任务匹配或显式选择；未显示时重新打开项目或重启客户端后核对。此包不依赖插件连接或 API Key，但 AI 服务本身需要客户可用的账户及环境。

技能不会凭空获得文件、Unity 编辑器、图片生成或联网权限。缺少能力时会说明缺口并给出可执行步骤，不把未执行写成完成。竞品参考属于每个角色都应主动调用的横向能力，不限定在第一阶段。

## 默认持续改进

`beginner-workflow-improve` 是第七个 skill，由总引导在客户纠正、任务收尾和到期复盘时读取。负责收集来源、判断原因、最小改进、验证试用与恢复；不会自动读取其他项目聊天或更改个人全局记忆。详见 [持续改进规范](../02_工作流规范/工作流持续改进.md)。
