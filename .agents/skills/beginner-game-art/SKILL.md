# 面向游戏使用的美术指导

读取 `AGENTS.md`、`项目记录/美术风格与资产清单.md`、当前界面与需求。客户只需描述感受，由 AI 转成构图、颜色、层次、可读性和资产规格。遇到风格或界面不确定，主动使用 `beginner-game-reference` 查可观察的参考，给出取舍。

## 制作顺序

1. 先确定观看尺寸与用途：桌面背景、角色立绘、证件底板、印章、图标、按钮、特效，各自规格不同。
2. 建立小型风格基准：明暗、配色、轮廓、材质、时代感、光向、视角、像素/非像素、文字留白。只用已确认项；像素画不自动等于 Papers, Please 类型。
3. 给客户 2–3 个有明确体验差异的方向；先验收一张实际尺寸的代表画面及一组资产，再批量生成。
4. 按 `references/提示词与验收.md` 产出可直接使用的提示词、负面约束、导出规格和接入要求。使用工具生成图片须确认工具与授权可用；只有提示词时标记“提示词完成，图片未生成”。
5. 每批检查一致性和游戏内可读性；证件文字、动态姓名、日期、规则等交给 UI 文本系统排版，避免生成图把规则文字焊死。

## 交付与审查

资产记录包含 ID、用途、文件、版本、尺寸、透明背景、来源/授权、生成提示词、导入设置、界面引用、游戏内验证。检查文字区域、切片/锚点、遮挡、缩放、点击区域和状态反馈。声音也要登记来源、用途和音量验收，不把图像提示词当作全套视听制作。

正确性审查检查是否匹配体验、规格和可读性；必要性审查检查是否过早批量生产、重复资源或生成了程序能更可靠绘制的文本。最终画面需在目标分辨率的游戏里验证，联系程序技能完成接入。

## 真实资源生产入口

做样本与批量资源前读取 `02_工作流规范/美术音频实际生产.md`。先核对图像和音频各自的实际工具、账号、成本与授权，再确定 AI 直做、客户操作或授权素材路线。先交付真实图像与声音样本并完成 Unity 接入验证，再批量制作；不可只把提示词交给客户就结束。文件位置、回传步骤、导入责任与占位替换任务写入本步操作卡。
