# 推进提示词库

客户在网页“推进提示词”中选择场景，点复制，再粘贴到项目 AI 对话。方括号里的内容可以用自己的话替换，也可以直接自由提问。

提示词正文唯一维护在 [prompts.json](../04_本地进度网页/prompts.json)，网页直接读取，不另维护一套不同版本。没有网页时让 AI 读取这个文件，选择对应条目。

| 情境 | 提示词 ID |
|---|---|
| 初次开始 / 日常继续 | start / continue |
| 模糊想法 / 完整范围 | idea / scope |
| 任意阶段的参考疑点 | reference |
| 核心玩法试验 / 美术 / 叙事 | prototype / art / story |
| 测试 / 报错 / 审查 | test / bug / review |
| 改想法 / 中断恢复 | change / resume |
| 完整交付 / 发布后维护 | release / maintenance |

你不需要记住 ID。也不需要每次提醒 AI 查竞品或 Review：这些已经写进 skills；提示词提供额外的明确入口。

## 版本补充入口

V0.2 新增 setup-check（环境准备）、action-card（具体操作）、scope-calibration（范围校准）、asset-production（真实资源生产）、release-patch（交付与补丁），总计 20 条。正文仍仅维护在 prompts.json。
